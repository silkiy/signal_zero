## Validasi konversi deadline

Perhitungan memakai offset eksplisit, tidak memakai timezone default host:

```powershell
$jamDeadline = [DateTimeOffset]::Parse('2026-12-01T13:37:00-08:00')
$jamDeadline.ToUniversalTime().ToString('yyyy-MM-dd HH:mm:ss zzz')
$jamDeadline.ToOffset([TimeSpan]::FromHours(7)).ToString('yyyy-MM-dd HH:mm:ss zzz')
```

Output teramati: `2026-12-01 21:37:00 +00:00` dan `2026-12-02 04:37:00 +07:00`. Nilai sumber berasal dari [pengumuman GitHub](https://github.blog/open-source/gaming/game-off-2026-the-theme-is-shift/).

Verifikasi dokumen lokal: kedua file terbaca, memuat sumber tahun 2026/tanggal WIB/deadline; tautan lokal evidence ke specification berhasil di-resolve dan ID task rilis yang dirujuk ada pada backlog.
