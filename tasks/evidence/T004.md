## Command actual

- `flutter build web --release --no-web-resources-cdn --dart-define=WEB_PROBE=true` → PASS setelah callback JS interop diubah menjadi closure. Initial compile menolak tear-off `_fileInput.click`; error tersebut tidak dianggap build sukses.
- `python tools/web_probe_server.py --build apps/game/build/web` → app 127.0.0.1:8191, separate-site iframe host localhost:8192, tanpa COOP/COEP.
- `node tools/web_probe_browser.cjs` dengan Playwright bundled 1.62.1 dan `channel: chrome` → exit 0. Profil baru per skenario, tidak memakai data browser pengguna.
- `flutter test test/web_probe_test.dart` → red sebelum codec tersedia, lalu green 4 tests: round-trip, version/unknown fields, typed/range bounds, raw-size/malformed JSON.

## Batas yang tetap terlihat

- Tidak menguji offline reload/cold install; hanya continued operation setelah aset dan worker termuat.
- Audio headless menguji state API dan mute, bukan kualitas/keluaran speaker fisik.
- Tidak ada browser/mobile/hosting di luar Chrome desktop yang dinyatakan lulus.
- Build memberi warning font tree-shaking `CupertinoIcons` pada template empty/Material-only. Tidak ada ikon Cupertino di UI probe/shell dan runtime uji tidak mencatat error. Evaluasi konfigurasi font pada packaging T094; tidak disembunyikan sebagai error analyzer.
- Tidak ada produksi engine, progress schema, editor, backup, wallet, backend atau contract yang diimplementasikan oleh probe.
